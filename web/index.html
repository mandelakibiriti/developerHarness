How the harness works

DevEx Harness is a dashboard that runs on your own machine. It helps you take an idea from a written spec to working code with an AI agent, while keeping you in charge and showing what the AI did.

  1. Connect a modelAdd a provider API key in Settings.
  2. DesignArchitect writes the spec to docs/. Map turns it into a blueprint with a build order.
  3. TrailAllows you to review the agent's sessions
  4. CheckReview the spec in Plannotator. Telemetry and Trail show every AI call.

The Skill selector sets how much the agent does for you: beginner means you write the code with hints, advanced lets it do more, behind gates (checks it must pass). Your files, keys and logs stay on this machine; what you send to the agent goes to the model provider you chose.
